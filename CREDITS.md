## Chaînes de démonstration (catégorie « Demo Channels »)

Flux de test HLS publiés par Apple pour les développeurs (« HTTP Live Streaming examples »,
https://developer.apple.com/streaming/examples/), servis par `devstreaming-cdn.apple.com`. Ils sont utilisés tels
quels, uniquement par lien, comme le prévoit leur publication pour tester les lecteurs HLS.

| Chaîne | Flux |
|---|---|
| Démo 1 | BipBop 16:9 (`bipbop_16x9_variant.m3u8`) |
| Démo 2 | Exemple avancé, fMP4 (`img_bipbop_adv_example_fmp4/master.m3u8`) |
| Démo 3 | Exemple avancé, MPEG-TS (`img_bipbop_adv_example_ts/master.m3u8`) |
| Démo 4 | BipBop 4:3 (`bipbop_4x3_variant.m3u8`) |

Programmes du guide (`epg.xml`) : fictifs, écrits pour cette démo.
